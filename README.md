# \# SHAPES (Stokes Hydrodynamics for Aggregate Particles via Ensemble of Spheres)

# 

# This MATLAB program package is designed to calculate the resistance tensors for a particle of any shape in Stokes flows. A particle is modelled as an aggregate of small, rigid, and hydrodynamically interacting beads. The method to compute resistance tensors is largely based on the Stokesian Dynamics algorithm (Durlofsky et al. 1987).
